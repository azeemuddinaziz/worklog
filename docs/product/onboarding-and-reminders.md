# Onboarding and reminders

## Goal

Help the user become comfortable with the agent and build the habit of logging every day.

## Guided tutorial (V1)

A step-by-step product tour that ends with a real first log:

1. Meet the agent.
2. Create your first Project.
3. Dump a sample day.
4. Review the Review Draft.
5. Approve it.
6. Set up the daily reminder.

Guided backfill of past work is **not** part of V1; users can still type past work into the chat manually.

## Daily reminder (V1)

The user is guided to create a recurring ~15-minute "log your day" event in their own calendar, shortly before their shift ends (for example Google Calendar). The calendar does the notifying. No deeper calendar integration in V1.

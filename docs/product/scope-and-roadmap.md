# Scope and roadmap

## V1

- Chat with the agent (text), persistent Conversation history
- Projects (create, edit, archive); agent routing across Projects
- Capture: clarifying questions, inline path, Review Draft path, per-Log-Entry approval
- Content Types: Work, Manager/people issue, Office politics, Learning/win/blocker
- Estimated dates for multi-day or vague work, marked until confirmed
- Browse Worklog by Project and day; revision history; archive/restore with trail
- Ask the agent about the Worklog; agent stays in professional scope
- Resume points on request ("I'm updating my resume for this role, give me impactful points on these Projects")
- Guided onboarding tutorial and calendar-based reminder guidance
- Private, single-user Worklogs

## Later (V2+)

- Job description in, tailored resume out, with a nudge where the JD doesn't match the Worklog
- Guided backfill of past work (coarse to fine: week, then Project, then day)
- Voice input (for example via a voice partner such as Wispr Flow)
- Deeper calendar integration

## Explicitly out

- Deleting Log Entries
- Teams, sharing, manager visibility
- General-purpose assistant behaviour
